# Architecture (Reference)

This repo is a documentation-only project that tracks the development of the project-os template. There is no application code — only documentation artifacts (features, requirements, ADRs, tasks) that plan changes to the template repo at `~/Dev/repos/project-os`.

## Canonical entrypoints
- Read `SNAPSHOT.yaml` for current project state
- Read `docs/INDEX.md` for documentation navigation
- Implementation target: `~/Dev/repos/project-os` (the template repo)

## Key directories
- `docs/`: documentation system (features, requirements, decisions, tasks)
- `docs/features/`: feature notes with plans and task breakdowns
- `docs/requirements/`: requirement specifications
- `docs/decisions/`: architecture decision records (ADRs)
- `tools/`: instructions and playbooks (inherited from project-os template)
